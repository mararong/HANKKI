# 한끼 식습관 분석

한끼는 하루 동안 먹은 음식을 기록하고, 섭취한 열량과 영양소를 날짜별로 비교할 수 있는 웹 프로그램입니다.

- **식사 기록** — 아침·점심·저녁과 간식에 먹은 음식과 중량을 기록하고 나중에 수정할 수 있습니다.
- **음식 검색** — 음식 이름을 입력하면 식품의약품안전처 API에서 일반 음식과 식재료를 찾아 보여 줍니다. 재료와 요리 이름의 순서가 달라도 같은 메뉴를 찾고, 정확히 일치하는 음식은 한 건으로 표시합니다. 같은 이름의 음식은 하나로 모으고 제조사별 제품은 제외합니다. 검색 결과에 없는 음식은 제품의 영양표시를 보고 직접 추가할 수 있습니다.
- **영양성분 계산** — 먹은 중량을 기준으로 열량, 탄수화물, 단백질, 지방, 식이섬유, 나트륨을 계산하고 끼니별·하루별 합계를 보여 줍니다.
- **기간별 리포트** — 일간·주간·월간 그래프로 열량과 영양소 섭취량의 변화를 확인할 수 있습니다.
- **식단 피드백** — 하루 기록을 완료하면 식이섬유와 나트륨 섭취량을 영양표시 기준치와 비교하고 다음 식사에 참고할 팁을 제공합니다.
